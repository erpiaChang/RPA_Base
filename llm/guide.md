# 주문 자동화 RPA 사용 설명서

## 1. 무엇을 하나
PC 에서 ERPia 를 사람 대신 조작해 주문을 처리하는 프로그램이다. 창 이름은 [주문 자동화] 이다.
기능은 네 가지이고, 고른 것만 늘 이 순서로 돈다 (고른 순서와 상관없다).
1. 메일 엑셀 받기 — 메일 사이트에 로그인해 주문 엑셀이 붙은 메일에서 엑셀을 받는다. 로그인 때 휴대폰 인증 문자가 필요하다.
2. 주문수집·매출처리 — ERPia 주문매핑 화면에서 주문을 모으고(엑셀수집 → 자동수집) 매출처리한다.
3. 물류대기 — 재고가 모자란 상품에 배송보류를 걸고, 나머지를 저장해 물류처리로 넘긴다. 물류대기 메뉴가 없는 계정은 건너뛴다.
4. 물류관리 — 개별배송으로 등록하고 택배사·박스를 지정해 저장한다. [자동] 이면 저장 뒤 [운송장출력], [수동] 이면 [엑셀파일생성] 을 누른다.

## 2. 실행 창 — 탭 넷과 [설정] 의 칸
- 창 위쪽에 탭이 넷 있다: [홈] [예약] [실행 기록] [설정].
- [홈]: 맨 위 한 줄이 지금 상태다. 값이 비어 실행할 수 없으면 옆의 [설정에서 넣기] 가 그 칸으로 데려간다. 그 아래 실행할 기능과 [바꾸기], 큰 [실행] 단추, 다음 예약과 [예약 바꾸기], 마지막 실행이 있다.
- [예약]: 자동 실행 설정 (4절). [실행 기록]: 지난 실행을 새 것부터 보인다. 건너뛴 예약도 같은 표에 남는다(같은 이유가 이어지면 한 줄에 횟수). 줄을 두 번 누르거나 골라서 [결과 보기] 를 누르면 그때의 결과(리포트)가 열린다.
- [설정]: 한 번 정하면 거의 바꿀 일이 없는 값이다. 기능별 묶음으로 나뉘고, 칸을 누르면 아래에 설명이 나온다. 이 프로그램에 없는 기능의 묶음은 보이지 않는다.
- [실행할 기능]: 네 기능 중 하나 이상 체크한다. 고르지 않은 기능의 칸은 잠긴다. "기능 고정" 으로 받은 프로그램은 여기서 기능을 바꿀 수 없다.
- [ERPia 프로그램]: 비어 있거나 맞지 않으면 켤 때와 [실행] 할 때 이 PC 에서 찾아 넣는다. 다른 곳에 설치했으면 [찾기] 로 고른다.
- [엑셀 저장 폴더]: 메일에서 받은 엑셀을 날짜별로 저장할 폴더. 처음에 [찾기] 로 고른다. 비어 있거나 없는 폴더면 [실행] 이 잠긴다.
- [사이트 비밀번호]: 메일 사이트 로그인 비밀번호.
- [ERPia 비밀번호]: ERPia 로그인 비밀번호. 두 비밀번호는 이 PC 에서만 풀리게 감싸서 저장된다. 아이디·업체코드는 담당자가 넣어 두어 바꿀 수 없다.
- [수집방식]: [자동수집](ERPia 가 사이트에서 직접 가져온다) / [엑셀수집](메일로 받은 엑셀을 올린다). 하나 이상. 둘 다면 엑셀수집 → 자동수집 순서. 메일 엑셀 받기를 쓰면 [엑셀수집] 을 꼭 체크한다 — 빼면 받은 엑셀을 올리지 않는다.
- [매출처리]: [전체 매출처리] = 조회 안 된 미매출 주문까지 / [선택주문 매출처리] = 조회된 주문만.
- [택배사] / [박스]: ERPia 물류관리 목록의 이름과 글자까지 똑같아야 한다 (예: 박스A).
- [자동/수동]: 물류관리 마지막 단추를 정한다. 자동 = [운송장출력], 수동 = [엑셀파일생성].
- [보류제외 상품코드]: 재고가 모자라도 배송보류를 걸지 않을 상품코드. 똑같은 코드만 해당된다. 여러 개면 쉼표로 나눈다.
- [엑셀 비밀번호]: 암호가 걸린 주문 엑셀의 비밀번호. 사이트마다 다르면 "사이트명=비번; 다른사이트=비번" 으로 적는다. 비밀번호가 없는 엑셀은 건너뛴다 (틀린 값을 넣어 파일이 잠기는 것을 막는다).
- [인증 문자]: 인증 문자를 읽는 방법. [휴대폰 연결](PC 의 휴대폰 연결 앱, 케이블 필요 없음) / [adb (USB 케이블)] / [adb (무선)] / [자동으로 고름]. 잘 모르면 [휴대폰 연결] 을 쓴다.
  - adb 두 가지는 담당자가 이 PC 에 adb 를 설치해 준 경우에만 고른다. USB 는 휴대폰 [개발자 옵션] 의 [USB 디버깅] 을 켜고 허용 창에서 승인한다. 무선은 담당자가 한 번 연결(페어링)해 준 뒤, 휴대폰 [무선 디버깅] 화면의 연결용 "IP:포트" 를 [무선 주소] 칸에 적는다.
- [설정] 탭의 값은 바꾸면 바로 저장된다("저장했습니다", 따로 저장 단추는 없다). 실행하는 동안에는 칸이 잠긴다.

## 3. 실행하기
- 창을 켜면 먼저 서버에서 이 PC 를 확인한다. "서버에 이 PC 를 확인하는 중입니다..." 동안 [실행] 이 잠긴다. "서버 확인을 마쳤습니다. [실행]을 누르세요." 가 뜨면 누른다.
- [실행]: 고른 기능을 돌린다. RPA 는 실제 마우스·키보드로 ERPia 를 누른다. 도는 동안 사람은 마우스·키보드를 만지지 않고 ERPia 위에 다른 창을 띄우지 않는다 — 손을 대면 멈출 수 있다.
- [실행] 을 누르면 [홈] 이 진행 화면(진행 단계·상세·진행 로그)으로 바뀐다. 끝나도 남고, [처음 화면]·[진행 화면] 으로 오간다.
- 진행 단계는 큰 단계 넷(메일 엑셀 받기 → 주문수집·매출처리 → 물류대기 → 물류관리, 고른 것만) 아래에 세부 단계가 줄로 나온다. 진행 로그의 "[2/4]" 는 넷 중 둘째라는 뜻이다.
- 실행하는 동안에는 [홈] 에 고정된다. [예약]·[실행 기록]·[설정] 탭은 잠기고, 끝나면 다시 열린다.
- 도는 동안 ERPia 위에 진행 표시가 뜬다. 단추: [일시정지](다음 대기 지점에서 멈춤, [계속하기] 로 잇는다) / [숨기기]·[보이기] / [펼치기]·[접기] / [상세] / [중단]. [홈] 아래에도 [일시정지]·[중단]·[화면 위 진행 표시] 가 있다. 실행 중의 [일시정지] 는 도는 실행을, [예약] 탭·웹의 [일시정지] 는 예약을 멈춘다.
- RPA 가 로그인할 때 이 PC 에 같은 업체코드·아이디로 로그인된 ERPia 가 있으면 RPA 가 그 창을 닫고 다시 로그인한다. 예약 5분 전에 그런 ERPia 가 켜져 있으면 알림 창이 뜬다 — 작업을 저장하거나 [이번만 건너뛰기](그 한 번만 안 돈다). 안 누르면 예약 시각에 돈다.
- [중단]: 도는 동안만 [홈] 아래에 나온다. 지금 단계에서 빠져나온다. 이미 저장된 것은 되돌리지 않는다.
- [결과 보기]: 마지막 실행의 결과(리포트)를 연다. 문제가 있으면 이 리포트 파일을 담당자에게 보낸다.
- 메일 엑셀 받기가 실패해도 뒤에 고른 기능은 이어서 한다 (이유: [확인할 것]).
- 실패하면 "이미 끝난 것 / 하지 못한 것 / 다시 실행하면" 이 나온다. 실패·중단 뒤 [홈] 아래 [멈춘 곳부터 다시] 는 멈춘 기능부터 끝까지 한 번 돈다([실행할 기능] 은 그대로). 어느 쪽이든 받은 메일·올린 엑셀·매출처리한 주문·건 배송보류는 다시 하지 않는다.
- Windows 화면이 잠겨 있으면 자동화가 동작하지 않는다 (Windows 제약). PC 를 켜 두고 로그온한 상태로 둔다.
- 프로그램은 쓰기가 되는 폴더(바탕화면 등)에 둔다.
- 메일 엑셀 받기를 처음 실행하면 프로그램 옆에 [driver] 폴더(메일 브라우저용)가 생긴다. 지워도 다시 만든다.

## 4. 자동 실행 (예약)
- [예약] 탭의 [자동 실행] 을 체크해 켠다. 기본은 꺼짐이다. 켜면 사람 없이 실제 계정으로 저장까지 돈다.
- 방식 두 가지: [정해진 날·시각] / [정해진 간격].
- 정해진 날·시각: 한 줄에서 [반복] 목록을 고르고(→ [매일] / [요일 지정] / [매월] / [날짜 지정]), 옆에 나오는 칸을 채우고, 시각(시:분, 07 처럼 직접 적어도 된다)을 고른 뒤 [추가] 를 누른다. [추가] 를 누르면 바로 저장된다. 예약은 12개까지. 지울 때는 목록에서 줄을 골라 [삭제].
  - [요일 지정] 을 고르면 월·화·수·목·금·토·일 체크가 나온다. 평일은 월~금 다섯 개를 체크한다. 주말은 토·일.
  - [매월] 을 고르면 날짜(1~31)를 고른다. 그날이 없는 달(예: 31일)은 그달을 건너뛴다.
  - [날짜 지정] 은 "2026-09-25" 처럼 적는다. 그날 한 번만 돈다.
- [이 예약의 기능] 은 [추가] 를 누르기 전에 체크한다. 체크하면 그 예약에는 그 기능만 돈다 (예전 줄처럼 기능이 없으면 [실행할 기능] 대로). 같은 시각에 걸린 예약이 여럿이면 기능을 합쳐 한 번 돈다.
- 예) 평일 오전 9시에 메일·주문수집만 돌리기: 1) [자동 실행] 체크 2) [정해진 날·시각] 3) [반복] 에서 [요일 지정] → 월·화·수·목·금 체크 4) 시각 09:00 5) [이 예약의 기능] 에서 메일 엑셀 받기·주문수집·매출처리 체크 6) [추가].
- 정해진 간격: 10~1440분. 앞 회차가 끝난 때부터 센다. 고친 뒤 [적용].
- 예약은 이 프로그램이 켜져 있을 때만 돈다 (최소화는 괜찮다). 꺼져 있던 시각의 예약은 기록 없이 지나가고 나중에 몰아서 돌지 않는다. 늘 켜 두려면 자동 켜기(5절)를 쓴다.
- 프로그램이 켜져 있는데 그 회차를 건너뛰는 경우: 화면이 잠겼다 / 앞 회차가 아직 돈다 / [일시정지] 를 눌렀다 / 10분 넘게 늦었다(PC 잠자기) / 경고 창에서 [이번만 건너뛰기]. 건너뛴 회차도 실패한 회차도 몰아서·곧바로 다시 돌지 않고 다음 예약을 기다린다.
- [일시정지]: 예약만 멈춘다. 누르면 [계속하기] 로 바뀌고, 그것을 누르면 다시 돈다. 웹의 [일시정지]/[계속하기] 와 같은 것이다 (어느 쪽에서 풀어도 된다). RPA 프로그램을 껐다 켜도 멈춤이 이어진다.
- 예약 회차의 결과는 [실행 기록] 탭에 다른 실행과 함께 나온다. 건너뛴 회차는 "건너뜀" 으로 남는다. 다음 예약 시각은 [홈] 의 [다음 예약] 줄과 [예약] 탭 위쪽에 나온다.
- 메일 엑셀 받기가 든 예약은 30분 전부터 5분마다 휴대폰 인증 준비를 미리 본다(아무것도 누르지 않는다). 결과는 [다음 예약] 줄 아래에 나오고, 안 되면 알림 창이 한 번 뜨고 업체 담당자에게 메일이 간다. 실행은 그대로 돈다.

## 5. 자동 켜기
- 처음 켤 때 "PC 에 로그온하면 이 프로그램을 자동으로 켤까요?" 를 묻는다. [예] 면 로그온할 때 켜지고, 창을 닫아도 5분 안에 작게(최소화) 다시 켜진다.
- 나중에 [설정] 탭 [프로그램] 묶음의 [PC 에 로그온하면 켜고, 꺼져 있으면 5분 안에 다시 켜기] 체크로 끄고 켠다.
- 이미 켜져 있으면 두 번 켜지지 않는다. 사람이 또 누르면 "이미 켜져 있습니다" 가 뜬다 — 작업 표시줄에서 [주문 자동화] 창을 연다.
- PC 전원이 꺼져 있거나 로그온 전이면 켤 수 없다.

## 6. 프로그램과 PC
- 프로그램은 처음 켜진 PC 에 묶인다. 다른 PC 로 복사하면 서버가 거부해 [실행] 이 잠긴다.
- PC 를 바꾸면 담당자에게 새 프로그램을 받는다.

## 7. 웹 대시보드
- 이메일과 비밀번호로 로그인한다. 가입 화면은 없다 — 계정 만들기·비밀번호 재설정은 관리자에게 요청한다. 브라우저 탭을 닫으면 로그아웃된다.
- 위쪽 탭: [요약](진행 중인 실행) / [사용량] / [PC] / [실행 기록](실행 상세·엑셀 내려받기, 90일까지). [사용법 질문]은 옆 패널.
- [요약]·진행 중인 실행 상세는 5초, [실행 기록]은 30초마다 새로 고친다. 오래된 기록은 자동으로 지워진다.
- 무인 실행(예약·웹 [실행])의 실패·확인할 것, [사용자 계정 컨트롤] [예]·휴대폰 확인이 필요할 때는 업체 담당자에게 메일이 간다(관리자가 설정한 경우).
- 실행 상태: 진행 중 / 완료 / 완료(끝나지 않은 단계 있음) / 실패 / 중단 / 끝나기 전에 끊김 / 건너뜀.
- PC 를 누르면 그 PC 화면이 열린다. PC 는 30초마다 신호를 보내고, 90초 넘게 신호가 없으면 "꺼져 있거나 연결 안 됨" 으로 보인다.

### 웹에서 PC 제어
- 관리자와 그 업체의 담당자만 할 수 있다. 보기 전용 사용자에게는 "보기만 할 수 있습니다" 가 뜬다.
- [실행]: 실행할 기능을 하나 이상 체크하고 누른다. 확인 창이 뜬다. 예약 회차처럼 사람 없이 돈다.
- [RPA 종료]: 실행 중일 때만 눌린다. 도는 실행을 지금 단계에서 멈춘다. 저장된 것은 되돌리지 않는다.
- [일시정지]: 일시정지가 아닐 때만 눌린다. 예약만 멈춘다 (도는 실행은 멈추지 않는다). [계속하기]: 일시정지일 때만 눌린다.
- 명령은 PC 가 켜져 있으면 30초 안에 가져간다. PC 가 꺼져 있으면 켜진 뒤 가져가고, 10분이 지나면 버린다.
- 이미 실행 중이거나, 화면이 잠겼거나, 서버 확인 전이면 [실행] 을 시작하지 않고 그 이유를 [명령 기록] 에 남긴다.

### 웹에서 설정 바꾸기
- 비밀번호와 PC 의 폴더 경로를 뺀 값(실행할 기능, 수집방식, 매출처리, 택배사, 박스, 자동/수동, 보류제외 상품코드, 인증 문자, 자동 실행)을 바꿀 수 있다. 비밀번호와 경로는 PC 의 실행 창에서만 넣는다.
- PC 를 한 번 켜야 그 PC 의 값이 올라와 웹에서 바꿀 수 있다.
- 저장하면 PC 가 30초 안에 받는다. PC 가 실행 중이면 설정 칸이 잠기고 저장할 수 없다 — 실행이 끝나면 다시 바꾼다.
- 그 사이 다른 사람이나 PC 가 값을 바꿨으면 저장이 거부되고 새 값을 불러온다. 다시 고쳐 저장한다.

## 8. 이런 말이 보이면
- "ERPia 아이디 또는 비밀번호가 맞지 않습니다" → [ERPia 비밀번호] 를 고친다. 고치지 않고 되풀이하면 계정이 잠길 수 있다. 아이디가 바뀌었으면 담당자에게 알린다.
- "화면이 잠겨 있어 진행할 수 없습니다" → 잠금을 풀고 다시 실행한다.
- "같은 ERPia 아이디가 이 PC에서 이미 로그인돼 있습니다" / "ERPia가 이미 켜져 있습니다" → 켜져 있는 ERPia 를 모두 닫고 다시 실행한다.
- "ERPia가 업데이트 뒤 관리자 권한으로 다시 켜져서 RPA가 다룰 수 없습니다" → 그 ERPia 로그인 창을 닫고 다시 실행한다.
- "ERPia 프로그램을 찾지 못해 실행하지 않았습니다" / "ERPia 실행 파일을 찾지 못했습니다" → 이 PC 에 ERPia 가 설치돼 있는지 확인한다. 다른 곳에 설치했으면 [ERPia 프로그램] 을 [찾기] 로 고르고, 모르면 설치해 준 담당자에게 문의한다. 이 실패는 [실행 기록] 에도 남는다.
- Windows [사용자 계정 컨트롤] 창 → 사람이 [예] 를 누른다. RPA 는 이 창을 누를 수 없다. "업데이트 안내 창을 사람이 확인해 주세요" 도 사람이 처리한다.
- "메일 사이트에 로그인하지 못했습니다" → [사이트 비밀번호] 를 확인한다.
- "메일 인증을 통과하지 못해 1분 뒤 다시 시도합니다" / "인증번호 문자가 오지 않아 1분 뒤 다시 요청합니다" → 기다리면 된다 (누를 것 없음). 인증번호가 안 오면 1분 뒤 두 번까지 다시 요청하고, 그래도 안 되면 메일 받기를 멈춘다.
- "인증 문자가 제시간에 오지 않았습니다" / "휴대폰이 PC와 연결돼 있지 않아 인증 문자를 받을 수 없습니다" → 휴대폰 화면을 켜고 PC 의 [휴대폰 연결] 앱이 '연결됨' 인지 본 뒤 다시 실행한다. 휴대폰 화면을 오래 꺼 두면 연결이 끊긴다.
- "PC에서 [휴대폰 연결] 앱이 켜져 있지 않습니다" → 앱을 켜고 '연결됨' 을 확인한다.
- "[휴대폰 연결] 앱에 문자가 보이지 않습니다" → 휴대폰의 [Windows와 연결] 앱에서 문자 동기화(모바일 데이터 포함)를 켠다.
- "USB로 연결한 휴대폰에서 인증 문자를 읽지 못했습니다" → 케이블과 휴대폰의 [USB 디버깅] 허용을 확인한다.
- "인증 문자에서 인증번호를 하나로 고르지 못해 멈췄습니다" → 잠시 뒤 다시 실행한다.
- "ERPia 물류관리의 [택배사] (또는 [박스]) 목록에 없는 이름입니다" → 함께 나온 "목록에 있는 이름" 과 글자까지 똑같이 [택배사]/[박스] 를 고친다. "칸이 비어 있습니다" 면 값을 넣는다.
- "매출처리 중 ERPia가 오류를 알렸습니다" → 함께 나온 ERPia 메시지를 확인한다.
- "사이트 주문 수집이 제한 시간 안에 끝나지 않았습니다" → ERPia 화면에서 수집 상태를 직접 확인한다. 자동수집은 몇 시간 걸릴 수 있다.
- "멈췄습니다 — ERPia 화면에서 필요한 버튼이나 칸을 찾지 못했습니다" / "ERPia가 제시간에 반응하지 않았습니다" → 다시 실행한다. 같은 곳에서 또 멈추면 [결과 보기] 로 연 리포트 파일을 담당자에게 보낸다.
- "저장된 비밀번호를 풀지 못했습니다" → 비밀번호 칸에 다시 넣고 실행한다.
- "ERPia 알림 ... [확인]을 누르고 다음 단계로 넘어갔습니다" → 그 단계는 끝나지 않았을 수 있다. 리포트의 [확인할 것] 대로 ERPia 화면에서 직접 확인한다.
- 엑셀 한 건이 실패하면 표에 이유가 남고 나머지는 계속 돈다. "엑셀에 비밀번호가 걸려 있는데 등록된 비밀번호가 없습니다" → [엑셀 비밀번호] 에 넣는다. "ERPia 사이트 목록에 이 사이트 이름이 없습니다" → 엑셀 파일 이름의 첫 밑줄(_) 앞 사이트명이 ERPia 사이트명과 똑같은지 본다. "이 사이트에 [엑셀업로드] 버튼이 없습니다" → ERPia 에서 그 사이트의 엑셀수집 설정을 확인한다.
- 결과의 건수는 주문 수다. 한 주문에 상품이 여러 줄이어도 1건이다. 물류관리의 전표(송장)는 박스 수라 주문 수보다 많을 수 있다.
- 물류관리에서 개별배송으로 올릴 주문이 0건이면 오류가 아니다 — 할 주문이 없었거나, 남은 주문에 모두 배송보류가 걸려 있다는 뜻이다.
- "입력 필요: …" → 적힌 칸을 채운다. 채울 때까지 [실행] 이 되지 않는다.
- "입력 필요: 메일 사이트 연결"·"…: ERPia 실행 파일 이름" → 채울 칸이 없다. 담당자에게 알린다.
- "서버에 연결하지 못했습니다" → 인터넷 연결을 확인한다. 1분마다 다시 확인하고, 확인이 끝날 때까지 [실행] 이 잠긴다.
- "이 PC 에서는 이 프로그램을 쓸 수 없습니다" → 다른 PC 에 등록됐거나 사용이 중지된 프로그램이다. 담당자에게 새 프로그램을 받는다.

## 9. 사용법 질문 (이 기능)
- 웹 대시보드의 [사용법 질문] 에 적으면 답이 자동으로 만들어진다. 이 설명서를 바탕으로 하지만 틀릴 수 있다 — 실제 저장·삭제에 관한 것은 담당자에게 확인한다.
- 한 번에 하나씩 묻는다. 24시간에 50개까지. 답하는 PC 가 꺼져 있으면 질문을 받지 않는다.
